## 1. 目标

在 Mac 上完整复刻冻结版语雀网页编辑器的单人创作能力，包括工具栏、块菜单、富文本格式、复杂内容块、数据表、图形块、媒体、剪贴板、保存可靠性和无障碍行为。

本轮同时满足以下约束：

1. 文档为个人本地文档，iCloud 是唯一跨设备通道。
2. 不新增账号、多人协作、评论、提及、分享、收藏和持久版本。
3. Markdown 是可读主文档，复杂块使用版本化旁路数据。
4. 编辑器运行时资源全部随应用打包，不从 CDN 下载代码、字体、图标或模型。
5. 网络能力仅包括七牛媒体链路、用户主动打开链接和用户明确发起的粘贴媒体下载。
6. 本轮只交付并验证 Mac，iOS 编辑器、iOS UI 接入和 iOS 测试延期。

## 2. 非目标

- 不实现团队空间、成员、权限、邀请和实时协作。
- 不实现评论、回复、提及、在线状态、协作者头像和共享链接。
- 不实现收藏、星标、可见版本历史、版本比较或版本恢复。
- 不实现编辑器内在线 AI 执行、远程嵌入实时预览或第三方元数据抓取。
- 不在本轮接入 iOS 或建立 iOS 验收阻塞项。
- 不逐字复制语雀源代码、商标、专有图标和受保护素材。
- 不把七牛永久密钥放入 Mac 客户端、iCloud 或日志。

## 3. 文档状态

### 3.1 锁定状态

Markdown 文档有两个持久状态：

| 状态 | 正文编辑 | 标注 | 资源维护 | 工具栏 |
| --- | --- | --- | --- | --- |
| 未锁定 | 可以 | 可以 | 可以 | 完整编辑工具栏 |
| 已锁定 | 不可以 | 可以 | 可以 | 仅标注、目录、查找和资源操作 |

- 新建文档默认未锁定并进入编辑模式。
- 已有文档按 `manifest.json` 中持久化的锁定状态打开。
- 只有用户主动执行“完成编辑”才锁定。
- 切换材料、关闭窗口或退出应用只触发保存，不自动锁定。
- 锁定前必须完成正文保存并处理未提交标注草稿；失败时阻止锁定并显示原因。

### 3.2 未锁定时编辑与标注共存

- 未锁定文档提供显式的“编辑/标注”模式切换。
- 默认进入编辑模式。
- 同一段文字只能在当前活动模式下作为编辑选区或标注选区。
- 编辑模式继续显示已有标注高亮，并允许点击高亮定位或编辑标注。
- 创建新标注必须先进入标注模式，避免格式化菜单与标注菜单争抢选区。
- 锁定后完全隐藏编辑工具栏、斜杠菜单、块拖拽手柄和编辑快捷键。

## 4. 统一文档运行时

Mac 使用一个本地 WKWebView 文档运行时同时承载正文、标注、滚动、选区和大纲。

- 编辑器内核沿用 Tiptap/ProseMirror，扩展自定义节点和结构化命令。
- Swift 层负责文档生命周期、锁定状态、保存事务、媒体、快捷键和无障碍桥接。
- JavaScript 运行时全部构建期打包，不访问 CDN、遥测或远程字体。
- 正文与标注共享同一文档实例，保存后只重建派生视图。
- 拖拽、转换和块操作使用结构化命令，不直接修改 DOM。
- 中文输入法、撤销重做、选区和滚动状态在模式切换与保存后保持稳定。

## 5. 编辑界面

### 5.1 页面结构

编辑区采用居中画布和吸顶工具栏：

```text
文档标题
格式工具栏
正文画布
可选标注/AI 研读侧栏
```

- 工具栏在窄窗口内分组折叠或横向滚动，不遮挡正文。
- 标题、菜单、弹层和长文本不得重叠或撑破容器。
- 完整支持浅色、深色和跟随系统外观。
- 工具栏、菜单和弹层显示清晰标签或悬停说明。

### 5.2 富文本工具栏

工具栏至少覆盖：

- 撤销、重做、格式刷、清除格式。
- 段落样式、标题 H1-H6、字号、行距。
- 粗体、斜体、下划线、删除线、行内代码、链接。
- 文字颜色、背景高亮、对齐和缩进。
- 有序列表、无序列表和任务列表。
- 引用、分割线、代码块和文档内查找。
- 插入块入口、块类型转换和块拖动。

每个命令同时提供菜单、快捷键、禁用原因和当前选区状态。预设值与菜单层级以冻结版语雀基线为准。

### 5.3 斜杠菜单与块菜单

- 输入 `/` 打开可滚动、可搜索的插入菜单。
- 菜单至少分为基础、智能、画板类；不含需要账号或他人的入口。
- 块悬浮手柄支持转换为、删除、复制、剪切、缩进、下方添加和拖动排序。
- 支持跨块多选后的复制、剪切、删除和移动。
- 分栏、列表和折叠块必须执行合法嵌套约束；非法操作显示禁止状态。

## 7. Markdown 与旁路数据

### 7.1 映射原则

- Markdown 保存块顺序、稳定块 ID、轻量内容和可读降级内容。
- 原生 Markdown 可表达的内容优先使用原生语法。
- 下划线、颜色、背景、对齐等使用可读 HTML 标签或受控内联样式。
- 复杂块使用隐藏标识包围降级内容，完整状态写入独立块文件。
- 未知 Markdown、Front Matter、脚注和原始 HTML 继续作为兼容块保留。
- 旁路数据缺失、版本过新或解析失败时阻止保存并定位具体块。

块标识示例：

```markdown
<!-- studynotes:block id="8d2c..." type="data-table" version="1" -->
可读的降级内容
<!-- /studynotes:block -->
```

### 7.2 文件布局

```text
<material-id>.studyitem/
├── manifest.json
├── content/
│   ├── transactions/
│   │   └── <transaction-id>.json
│   └── generations/
│       └── <generation-id>/
│           ├── document.md
│           └── blocks/
│               └── <block-id>/
│                   ├── block.json
│                   ├── views/
│                   ├── records/
│                   └── assets/
├── annotations/
├── ai/
└── source/
```

- `manifest.json` 保存当前内容代 ID、文档锁定状态、标题、稳定标识和内容指纹。
- 用户只看到当前版本，不提供历史版本入口。
- 数据表使用 `schema.json`、`views/*.json` 和 `records/*.json`。
- 图形块保存场景数据、节点关系和本地资源；缩略图只作为本地缓存。
- SQLite 只保存可重建索引，不作为 iCloud 权威数据。

## 8. 保存与恢复

### 8.1 实时保存

- 每次编辑事务先追加本地恢复日志。
- 停止输入约 300 毫秒后形成原子快照。
- 切换材料、切换模式、锁定、进入后台、失焦和退出应用时立即刷新。
- 成功提交后可清除事务日志，不创建用户可见版本。
- 界面分别展示“已保存本地”“保存失败”“等待 iCloud 同步”。

### 8.2 代提交

1. 将新 Markdown、旁路块和提交标记写入新的内容代目录。
2. 校验所有文件、块 ID、版本和引用。
3. 原子更新 `manifest.json` 的当前内容代指针。
4. 原子保存成功后可删除旧代和事务日志。
5. 未完成代不可被读取器加载。

正文和旁路文件提交成功后，如果目录、全文索引、渲染缓存或标注锚点重建失败，保留正文并将派生状态标记为待重建，自动重试。核心内容成功不应因派生索引失败而回滚。

### 8.3 iCloud 冲突

- 以完整 `.studyitem` 为冲突判断单元。
- 同一文档在多设备并发修改后生成完整冲突副本。
- 用户选择保留哪个副本，不自动合并或拼装正文与块数据。
- 检测到外部修改时暂停覆盖，重新载入、保留本地副本或查看冲突由用户选择。

## 9. 标注

- 标注覆盖文本、标题、列表、引用、代码文本块和图片区域。
- 画板、思维导图、流程图和数据表只允许整体块引用或备注。
- 每次正文原子保存后重解析标注锚点。
- 能恢复的更新位置，不能恢复的标记为“位置待恢复标注”。
- 不因正文变化自动删除标注。
- 锁定后仍可创建、编辑、定位和删除标注。
- 编辑模式显示已有高亮；创建新标注先切换到标注模式。

## 10. 数据表

### 10.1 字段

支持单行文本、多行文本、数字、单选、多选、复选框、日期、日期时间、链接、邮箱、附件、公式、关联、汇总、自动编号、创建时间和更新时间。

不提供人员字段。没有账号体系时，人员没有稳定身份来源。

### 10.2 视图

支持表格、看板、日历和画廊视图，以及视图级筛选、排序、分组、字段显示隐藏、列宽和条件着色。

不提供表单、分享视图和公共提交。

### 10.3 计算

- 公式、关联和汇总均离线确定性计算。
- 关联可以引用同一知识库内其他文档的数据表。
- 目标缺失时保留关系和原始值，显示未解析引用。
- 支持循环依赖检测和批量重算。
- 不执行任意 JavaScript、脚本、网络或系统 API。
- 未支持公式显示可定位错误，不静默返回 0 或空值。

## 11. 图形块

- 默认提供可视化画布、直接节点操作和属性面板。
- 源码或 JSON 只作为高级入口。
- 画板、思维导图和流程图分别保存独立场景数据。
- 场景数据是权威内容，缩略图和渲染缓存可以重建。
- 图形编辑器必须离线工作，并支持撤销、重做、缩放、平移、键盘操作和减少动态效果。
- 具体开源引擎在实现前按许可证、包体积、离线能力、维护状态和无障碍能力选定。

## 12. 媒体

- 图片、附件、音频和视频继续上传私有七牛云。
- Markdown 保存 `media://qiniu/<objectKey>` 稳定引用，不保存签名 URL。
- 插入媒体后立即显示本地预览和上传状态。
- 离线时允许插入并进入待上传队列；应用重启后队列可恢复。
- 单文件默认上限为 50MB，保留原始内容，不自动压缩。
- 同内容跨文档去重。
- 删除块只移除引用，云端对象延迟清理。
- 清理前扫描 Markdown、块旁路文件、待上传队列和 iCloud 冲突副本。
- 已查看媒体保存在可清理的本地缓存；缓存丢失时正文仍可用，阅读态显示需联网获取。
- 设置页沿用共享 Bearer 密钥方案，永久七牛密钥只保存在 Web 服务端。

## 13. 剪贴板、导入与导出

### 13.1 粘贴

- 保留标题、格式、表格和链接。
- HTML 使用安全白名单清洗，移除脚本、事件处理器、远程样式和未知可执行内容。
- 无法安全转换的原始 HTML 保留为只读兼容块。
- 粘贴远程图片只在用户明确发起粘贴时下载并上传；默认不抓取其他远程资源。
- 失败时保留占位和原 URL，不后台重试或静默丢失。

### 13.2 导入

- 支持 Markdown 和受支持 HTML 导入。
- 未知语法、Front Matter、脚注和原始 HTML 保留为兼容块。
- 导入不执行源网页脚本。

### 13.3 导出

- `.md` 导出使用复杂块的可读降级内容。
- `.studynotes` 包导出保留 Markdown、旁路数据、标注、AI 会话和资源引用。
- HTML、PDF 和 Word 导出不属于本轮编辑器范围。

## 14. 界面与无障碍

- 工具栏、菜单、对话框、表格和图形块均提供键盘操作。
- VoiceOver 能读取控件名称、当前状态和禁用原因。
- 中文输入法、撤销重做、选区和滚动在各种模式切换下保持稳定。
- 减少动态效果、高对比度和深浅外观均作为验收条件。
- 工具栏、块菜单、表格和画布在窄窗口内不得相互遮挡。

## 15. 性能与降级

- 为超长正文、大量块、复杂图形和数据表建立实测性能预算。
- 超过预算时允许延迟加载、分页渲染和性能受限提示。
- 不允许通过截断、丢失块或禁止核心编辑能力规避性能问题。
- Apple Silicon 与 Intel Mac 都要建立基线；不能只在单一架构上验收。

## 16. 能力矩阵冻结

实现前必须审计冻结版语雀 Mac 网页编辑器，至少记录：

- 工具栏项目和预设值。
- 斜杠菜单、块菜单、子菜单和快捷键。
- 每种块的数据、编辑、复制、删除、转换和降级行为。
- 普通表格与数据表的全部字段、视图和公式。
- 编辑/标注选区仲裁、锁定和资源维护。
- Markdown、旁路数据、HTML 样式和未知语法往返。
- 离线、七牛上传、缓存和 iCloud 冲突状态。
- 深色、窄窗口、中文输入法和无障碍行为。

冻结矩阵已经发布为机器可读文件：

- [能力矩阵](../contracts/editor-capabilities.json)
- [JSON Schema](../contracts/editor-capability.schema.json)
- 固定语料位于
  `apple/Packages/StudyNotesKit/Tests/StudyNotesKitTests/Fixtures/Editor/`。

每个能力包含稳定 ID、入口、快捷键、禁用条件、输入输出、Markdown 与旁路
数据映射、可用状态、联网限制、测试计划和交付状态。矩阵冻结后，任何新增
能力作为新任务进入，不允许以“差不多”替代验收。

## 17. 验收标准

| 编号 | 验收标准 |
| --- | --- |
| ED-M01 | 新建文档默认未锁定并进入编辑；已有文档按锁定状态打开 |
| ED-M02 | 未锁定文档可在编辑和标注模式间切换，锁定后正文只读但仍可标注 |
| ED-M03 | 编辑器和标注共享一个文档运行时，中文输入、选区、撤销和滚动不丢失 |
| ED-M04 | 工具栏、斜杠菜单和块菜单覆盖冻结矩阵中的全部单人能力 |
| ED-M05 | 所有初始块类型都能插入、编辑、移动、复制、删除和恢复 |
| ED-M06 | 普通表格、数据表、公式、Mermaid 和图形块往返不丢数据 |
| ED-M07 | Markdown 直接打开仍可读，复杂块有可读降级内容 |
| ED-M08 | 旁路缺失、版本未知和序列化失败时阻止保存并定位块 |
| ED-M09 | 300 毫秒内保存本地，崩溃后可从事务日志恢复 |
