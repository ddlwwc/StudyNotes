## What to build

为当前 Notebook workspace 建立本地全文索引，并提供 `Cmd+K` 搜索。用户可搜索页面标题、正文、标签和 PDF 文本，并从结果跳转到精确块或页码。

## Acceptance criteria

- [ ] Markdown 的标题、目录、正文、标签和 PDF 文本进入本地索引。
- [ ] 文件变化后只增量更新受影响内容。
- [ ] 删除索引或缓存后可从文件完整重建。
- [ ] `Cmd+K` 显示页面和正文搜索结果。
- [ ] 选择 Markdown 结果后打开页面并定位到对应标题或块。
- [ ] 选择 PDF 结果后打开正确页码。
- [ ] 黑盒测试验证索引、增量更新、重建和精确跳转。
