## What to build

让用户在 Notebook workspace 中打开带文本层的 PDF，翻页、缩放并选择文本。系统为选择内容生成可验证的 Source citation 锚点，为后续 PDF 辅导和复习提供稳定定位。

## Acceptance criteria

- [ ] 用户可从资料树打开 PDF，并使用只读查看器翻页和缩放。
- [ ] 用户可选择 PDF 文本，界面显示当前页码与选中片段。
- [ ] 系统保存路径、页码、片段和内容哈希组成的引用锚点。
- [ ] PDF 被外部修改后，可识别引用是否仍有效或已失配。
- [ ] 无文本层页面明确提示首版不支持 OCR。
- [ ] 黑盒测试打开真实 PDF、选择文本并验证引用锚点。
