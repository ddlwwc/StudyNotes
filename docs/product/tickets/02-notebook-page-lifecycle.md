## What to build

让用户从界面管理 Notebook workspace 中的 Markdown 页面，并让应用在 Finder、Obsidian 或 Git 修改文件后自动同步资料树。创建、重命名、移动和删除必须直接反映到文件系统，并保护用户已有内容。

## Acceptance criteria

- [ ] 用户可在选择的目录中创建 Markdown 页面。
- [ ] 用户可重命名和移动页面或目录，资料树与磁盘路径保持一致。
- [ ] 删除页面需要明确确认或进入系统废纸篓，不直接不可恢复删除。
- [ ] 在应用外新增、修改、移动或删除 Markdown 后，资料树自动刷新。
- [ ] 目录改名或丢失后显示可恢复提示，不删除已有学习记录。
- [ ] 黑盒测试验证应用内操作和应用外文件变化均产生正确磁盘结果。
