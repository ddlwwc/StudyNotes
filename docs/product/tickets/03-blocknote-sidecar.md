## What to build

把 Markdown 页面升级为 BlockNote 编辑体验。用户编辑后，页面仍以普通 `.md` 保存，同时由同名 sidecar 保存块结构和自定义属性；外部修改、自动保存与冲突处理必须保护用户内容。

## Acceptance criteria

- [ ] 用户可在 BlockNote 中编辑段落、标题、列表、引用、代码、表格和分隔线。
- [ ] 每次成功保存后，普通 Markdown 编辑器可读取完整 `.md` 内容。
- [ ] 块 ID、自定义属性和布局可通过 sidecar 保存并在重新打开时恢复。
- [ ] 缺少或损坏 sidecar 时，可从 Markdown 重建基础块并保留损坏文件备份。
- [ ] 外部修改且应用内无未保存内容时自动刷新。
- [ ] 外部修改且应用内有未保存内容时显示冲突，禁止静默覆盖。
- [ ] 异常退出后可恢复未保存草稿。
- [ ] 黑盒测试覆盖 Markdown、sidecar、外部修改和冲突的往返行为。
