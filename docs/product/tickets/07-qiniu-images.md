## What to build

让用户在 BlockNote 页面中粘贴或拖入图片。图片由本地后端上传到公开读七牛桶，Markdown 保存普通 HTTPS 引用；上传失败、缓存、旧图片迁移和删除确认均不会破坏笔记。

## Acceptance criteria

- [ ] 用户可配置七牛桶、访问域名和凭据，密钥只由系统 Keychain 保存和读取。
- [ ] 粘贴或拖入图片后显示上传状态，且仅在上传成功后写入 Markdown。
- [ ] 图片 URL 使用不可猜测的 workspace 哈希和随机对象键。
- [ ] 上传失败不修改 Markdown，并允许重试。
- [ ] 最近图片可在应用私有目录缓存，缓存失败不阻断页面保存。
- [ ] 已有本地相对图片仍可显示，只有明确迁移时才上传并改写。
- [ ] 从笔记移图时可选择是否删除云端对象；删页不自动删除。
- [ ] 黑盒测试模拟七牛成功、失败和删除流程。
