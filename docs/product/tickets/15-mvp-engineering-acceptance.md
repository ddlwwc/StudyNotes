## What to build

对完整 MVP 做发布前端到端验收，确认 Markdown、PDF、七牛图片、跨来源 Grounded tutor、练习、知识缺口、复习、备份和 macOS 桌面能够协同工作，并完成用户与工程门禁。

## Acceptance criteria

- [ ] 通过唯一黑盒 seam 覆盖首次启动、Markdown、PDF、图片、跨来源辅导、短答题、复习、备份和桌面启动。
- [ ] 5 位目标用户每人完成至少 3 次“提问 → 引用检查 → 练习 → 缺口 → 复习”闭环。
- [ ] 至少 60% 的 Practice item 被用户认为对理解有帮助。
- [ ] 无资料、笔记、会话、引用或复习记录丢失。
- [ ] 外部文件冲突、sidecar 损坏、索引删除和备份中断测试通过。
- [ ] 应用在 1280×800 与 1600×1000 视口下无文字重叠或关键操作遮挡。
- [ ] 用户能说明 Grounded answer 与 Unsupported supplement 的区别。
- [ ] 用户能通过上下文抽屉确认模型实际收到的资料。
