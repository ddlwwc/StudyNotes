# 笔记媒体保存到私有七牛云，Markdown 只保存稳定对象引用

Markdown 笔记中的图片和通用附件按内容去重后上传到私有七牛云，并在 Markdown 中保存 `media://qiniu/<objectKey>` 形式的稳定引用，而不是会过期的签名 URL 或要求公开 Bucket 的永久 CDN 链接。对象键采用 `library-media/<sha256-prefix>.<ext>` 的全局内容寻址格式，笔记媒体拥有独立于发布媒体的登记与清理生命周期；单文件上限为 50MB，默认保留原始内容。永久七牛密钥只保存在 StudyNotes Web 服务端，Mac 与 iOS 使用设置页配置、钥匙串保存的共享 Bearer 密钥调用笔记媒体接口，不建立设备登记或作用域；设置页同时显示服务端返回的 Bucket、下载域名和连接状态。设备端在 Application Support 中维护本地待上传队列，允许离线继续编辑，上传前显示本地预览，失败可重试；签名下载 URL 只存在于内存或短期缓存，已查看媒体进入可清理的本地派生缓存。删除正文媒体不立即删除云端对象，只有设置中的媒体清理确认对象不被当前正文或历史版本引用后才能删除；发布媒体使用独立命名空间，避免笔记清理破坏不可变文章版本。相比所有媒体都进入 iCloud 材料包，这节省了 iCloud 空间并集中管理大文件；代价是笔记媒体依赖七牛云和 StudyNotes Web 服务，私人媒体的跨设备可用性不再由 iCloud 单独保证。
