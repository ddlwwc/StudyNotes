# Mac 本轮完整复刻语雀式编辑器，iOS 延期

Status: accepted; supersedes the editor-delivery portions of ADR-0017, ADR-0018 and ADR-0020 for this release.

本轮只交付 Mac 语雀式编辑器。编辑器继续使用构建期打包的本地 WKWebView 与 Tiptap/ProseMirror 内核，但不再把 iOS 接入、iOS 交互和双端验收作为本轮交付条件。共享 `StudyNotesKit` 可以提供平台无关的编辑器核心，iOS UI 接入与测试延期到后续版本。

编辑器是单人、本地优先能力：不新增账号、实时协作、评论、提及、分享、收藏或持久版本；正文和块旁路数据属于 iCloud 中的 `.studyitem`，唯一跨设备通道是 iCloud。图片、附件、音频和视频继续上传私有七牛云，Markdown 只保存稳定对象引用和资源状态。

Markdown 仍是人类可读的主文档，但复杂块允许使用版本化旁路数据，因为数据表、画板、思维导图和流程图无法用普通 Markdown 无损表达。Markdown 保存块顺序、稳定块 ID、轻量内容和可读降级内容；复杂块以隐藏标识包围降级内容，完整状态存入 `content` 下的独立块文件。相比 ADR-0017 只允许原生 Markdown 可表达的能力，这一决定扩大了编辑器能力，但保留 Markdown 的可检查性与可迁移性。

新建 Markdown 文档默认未锁定并进入编辑模式。未锁定时可编辑也可标注，通过显式“编辑/标注”模式仲裁同一文字选区；锁定后正文只读，但仍可创建、编辑、定位和删除标注，也可以重试媒体资源。编辑器与标注共享同一个文档运行时，不再使用两套彼此独立的 DOM。

文档保存采用内容代目录与 manifest 提交指针。编辑事务先写入本地恢复日志，约 300 毫秒内形成可提交快照；所有正文和旁路文件写完后才切换当前内容指针。用户只看到一个当前版本，不提供历史版本；旧代在提交成功且不再需要事务保护后删除。iCloud 同步不承诺完成时间，跨设备并发修改仍以完整 `.studyitem` 冲突副本处理。

编辑器运行时除七牛媒体和用户主动打开或粘贴的链接外不依赖网络。在线 AI、协作和远程嵌入实时预览不在本轮范围；相关块可以保留禁用入口或离线卡片，但不得发起后台请求。媒体沿用 ADR-0021 和 ADR-0022 的私有七牛与共享 Bearer 密钥方案。

“完整复刻”以冻结版语雀 Mac 网页编辑器能力矩阵为唯一验收基线。截图只是输入；只有矩阵中的菜单、快捷键、块类型、选区行为、锁定行为、保存行为和离线降级均通过行为测试，功能才算完成。
