# 第一版笔记媒体接口使用共享 Bearer 密钥

Mac 与 iOS 的笔记媒体接口使用同一段随机 Bearer 密钥鉴权，密钥在设置页配置并保存在本机钥匙串，服务端保存其哈希。该密钥允许调用笔记媒体上传、读取、校验和清理接口，不区分设备、不设置作用域，也不支持单设备撤销；轮换密钥会让所有设备失效并需要重新配置。发布、回滚、下架和删除文章继续使用 Ed25519 发布签名，不因媒体鉴权简化而降低权限。当前部署允许 HTTP，因此 Bearer 密钥存在被链路攻击者截获的风险；客户端会显示安全提示，但不阻止非 HTTPS 地址。相比全网关签名和设备登记，这一方案显著降低了首版实现与配置成本，代价是密钥一旦泄露即可访问全部笔记媒体接口。
