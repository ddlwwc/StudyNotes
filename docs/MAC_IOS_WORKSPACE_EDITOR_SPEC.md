## 1. 目标

本轮改造解决以下问题：

1. 将设置、目录整理、编辑和媒体管理从分散入口收敛为稳定的工作台结构。
2. 让知识库只承担最高层身份，把文件夹编辑和材料组织放进材料目录栏。
3. 支持可折叠、可调宽的工作区，以及把文件夹和学习材料放在同一层级中的目录树。
4. 将 Markdown 笔记改为阅读区内嵌的所见即所得编辑器，不再使用创建或编辑弹框。
5. 将 Markdown 笔记媒体移出 iCloud 材料包，使用独立私有七牛媒体。
6. 在 iPhone/iPad 提供适合触屏的等价整理和编辑能力，不机械复制 Mac 三栏。

## 2. 非目标

- 不逐像素复刻语雀品牌视觉。
- 不实现多人协作、评论回复、插件市场、团队权限和企业嵌入。
- 不提供同级自定义排序；目录始终按名称为文件系统稳定排序。
- 不自动把历史本地媒体上传到七牛云。
- 不把网页文章、HTML、PDF 或图片隐式转换为 Markdown 材料。
- 不允许公开 Bucket，也不在 Apple 客户端保存永久七牛 AccessKey/SecretKey。
- 第一版不建设设备级媒体密钥、作用域和服务端设备撤销。

## 3. Mac 信息架构

主工作区由以下区域组成：

```text
知识库栏 | 文件夹与学习材料统一树 | 阅读/编辑区 | 可选研读层
```

### 3.1 知识库栏

- 入口：全部材料、收件箱、回收站、我的知识库、标签。
- “我的知识库”只显示知识库及其材料数量，不再展开文件夹和材料。
- 可见主操作只有新建知识库和删除知识库。
- 知识库重命名保留在右键菜单，作为修正名称的高级操作。
- 左下角固定设置入口和当前学习目录状态。

### 3.2 材料目录栏

材料目录栏以“知识库根目录”为根节点，把文件夹和学习材料放在同一棵可滚动层级树中，不再拆分为上方文件夹树和下方当前层材料列表。

- “知识库根目录”是可展开、可选择的节点；根级文件夹和根级学习材料直接排在它下面。
- 文件夹节点通过左侧箭头展开或收起；点击名称会选中文件夹、更新新建与导入目标，并清除材料多选。
- 学习材料是树的叶子节点；单击即选中并在右侧打开，`Command` 和 `Shift` 可多选当前树中可见的材料。
- 多选可以跨越已展开的文件夹；文件夹本身不进入材料选择集合。右侧继续显示最后打开的材料，不受文件夹选择或批量选择影响。
- 选择文件夹不会自动打开第一个子项。没有正在阅读的材料时，右侧显示“选择学习材料”。
- 同一层内始终先排文件夹、再排学习材料，两组分别按名称升序排列。
- 文件夹行显示该文件夹自身及其全部子孙文件夹中的学习材料总数，知识库根节点显示整个知识库的材料总数，空文件夹显示 `0`。
- 学习材料使用约 34–38pt 的单行紧凑行：类型图标、标题，以及冲突或 Web 发布状态；更新时间、标签和完整类型信息通过悬浮提示和右侧标题区展示。
- 文件夹展开状态按知识库、按设备保存在本地。首次进入知识库时只展开根节点，其余文件夹默认收起；导航到某个材料时自动展开其祖先文件夹。
- 新建文件夹后自动展开父目录、选中并显示新文件夹；新建笔记或导入材料后自动展开目标文件夹、选中并在右侧打开新材料。
- 搜索继续只覆盖学习材料、笔记、标注和 AI 文字结果。搜索时临时切换为跨层级扁平结果；清空搜索后恢复树，并展开当前阅读材料的祖先文件夹使其可见。
- “全部材料、收件箱、回收站、标签、搜索结果”保持扁平列表，使用约 44–48pt 的两行布局：首行标题，次行显示文件夹路径或状态。

### 3.3 栏宽与折叠

| 区域 | 默认宽度 | 可调范围 |
| --- | --- | --- |
| 知识库栏 | 184pt | 160–320pt |
| 材料目录栏 | 276pt | 240–480pt |
| 研读层 | 260pt | 220–420pt |

- 知识库栏、材料目录栏和研读层均可独立收起和展开。
- 分隔线支持连续拖动；双击恢复默认宽度。
- 宽度和折叠状态按设备保存在本地，不同步到 iCloud。
- 阅读区最小宽度为 420pt；正文最大宽度约 720pt 并居中。
- 所有侧栏收起后，工具栏必须保留明确的恢复入口。
- 隐藏和展开使用约 180ms 的平滑过渡，并尊重“减少动态效果”。

## 4. 文件夹与材料整理

### 4.1 右键菜单

文件夹菜单：

- 新建子文件夹
- 重命名
- 移动到…
- 新建 Markdown 笔记
- 导入材料
- 删除文件夹

空白区菜单：

- 新建文件夹
- 新建 Markdown 笔记
- 导入材料

材料菜单：

- 打开
- 移动到…
- 编辑标签
- 移入回收站

从文件夹菜单创建笔记或导入材料时，该文件夹自动成为目标位置。
选择知识库根节点后，从空白区菜单创建的文件夹、笔记或导入材料直接位于知识库根目录。
空白区菜单始终作用于当前选中的知识库根节点或文件夹，不作用于最后点击的学习材料。

### 4.2 拖放

- 只有文件夹节点和知识库根节点接受拖放；学习材料行不作为拖放目标。
- 文件夹拖到另一个文件夹：移动整个子树。
- 材料拖到文件夹：移动到目标文件夹，并自动展开目标文件夹。
- 材料或文件夹拖到知识库根节点：移动到知识库根目录。
- 拖动的材料属于多选集合时，移动整个已选集合；否则只移动当前项。多选集合可以跨越已展开的文件夹。
- 禁止把文件夹拖入自身或后代。
- 不支持拖放排序；不保存同级排序字段，同一层始终先显示文件夹，再按名称显示学习材料。
- 拖放目标必须显示高亮；悬停文件夹约 600ms 后可自动展开。
- iPhone 不提供自由拖放，使用“移动到…”表单完成等价操作。

### 4.3 动画

- 文件夹展开和收起约 160ms。
- 拖放目标高亮和悬停展开使用系统动画节奏。
- 插入、移动和删除后的列表变化使用非阻塞过渡。
- 开启“减少动态效果”时取消位移和缩放，只保留即时状态变化。

### 4.4 重命名与删除

- 文件夹重命名保留全部子孙路径、材料引用和当前选中状态。
- 名称冲突时不自动生成名称，要求用户输入新名称。
- 删除文件夹时，包含的材料进入回收站，子文件夹目录一并删除。
- 删除知识库沿用同一安全规则：材料进入回收站，不永久删除正文。

## 5. 设置

### 5.1 入口

- 左下角齿轮打开快捷菜单。
- 快捷菜单包含学习目录、AI 配置、发布配置、密钥与凭据、阅读偏好。
- 选择任意项目打开统一设置窗口的对应页面。
- 注册标准 macOS 设置命令 `Cmd+,`。

### 5.2 页面

| 页面 | 内容 |
| --- | --- |
| 学习目录 | 当前本地或 iCloud 目录、连接状态、切换目录、重建索引、派生缓存占用 |
| AI 配置 | 供应商、基础地址、模型 ID、Key 状态、连接测试、默认供应商 |
| 发布配置 | 服务器地址、笔记媒体密钥、连接测试、默认可见性、默认标注/AI 附录开关 |
| 密钥与凭据 | 发布密钥登记、轮换、撤销；AI Key 状态与跳转入口 |
| 阅读偏好 | 跟随系统/浅色/深色、正文字号、行高、行宽、代码字体 |

发布配置同时展示服务端返回的七牛 Bucket、下载域名、上传端点和媒体服务状态。笔记媒体密钥用密码输入框配置，底层保存在本机钥匙串，不写入 `UserDefaults`、iCloud 或日志。永久七牛密钥不在客户端显示或编辑。

### 5.3 默认值

- 发布默认可见性为未列出。
- 默认不发布标注。
- 默认不发布 AI 附录。
- 阅读偏好默认跟随系统外观。
- 阅读偏好按设备保存，不写入 iCloud。

## 6. Markdown 阅读与编辑

### 6.1 适用范围

- Markdown 笔记和 Markdown 文档支持内嵌富文本编辑。
- 网页文章、HTML、PDF 和图片保持现有阅读与标注方式。
- 后续如需编辑 HTML 或网页文章，应提供明确的“转换为 Markdown 学习材料”动作。

### 6.2 模式切换

- 新建 Markdown 笔记后直接进入阅读区编辑。
- 已有 Markdown 笔记默认进入阅读态。
- 点击编辑按钮、双击正文或按 `Cmd+E` 后原地切换为编辑态。
- 编辑态不打开弹框、不跳转页面。
- 阅读态保留文字选择和标注；编辑态暂停标注交互，避免编辑器抢占选区。

### 6.3 编辑器内核

- 使用构建期打包、运行时本地的 WebKit 编辑器内核。
- Mac 与 iOS 共享同一编辑能力和 Markdown 序列化实现。
- Swift 层负责文档生命周期、保存、版本、主题、快捷键和原生桥接。
- 编辑器内部文档树是会话状态，不是持久化真相。

### 6.4 首版能力

- 标题和正文
- 粗体、斜体、删除线、链接和行内代码
- 引用、提示块、分割线
- 有序列表、无序列表、任务列表和嵌套列表
- 代码块
- 表格
- 图片
- 通用文件附件块
- 撤销重做
- 常用键盘快捷键
- 斜杠菜单
- 块拖拽
- 文档大纲
- 文档内查找
- Markdown 源文本模式

以下能力不进入首版：数学公式、Mermaid、音视频播放器、外部嵌入、多人协作、评论和插件市场。

### 6.5 标题与 Markdown

- 编辑器标题块对应正文首个一级标题。
- 保存时同步更新 `manifest.json` 的标题和 Markdown 首个 `#` 标题。
- 旧文档两个标题不一致时，首次保存前要求用户选择，不静默覆盖。
- 任务列表、表格、代码块和提示块采用可逆的 Markdown 语法。
- Front Matter、脚注、原始 HTML 和未知语法以兼容内容块保留。
- 无法保证无损转换时阻止保存并说明原因，不允许静默丢弃内容。

### 6.6 保存与版本

- 正文停止输入约 800ms 后自动原子写入当前 Markdown。
- 切换材料、窗口失焦、应用进入后台或退出编辑态时立即刷新。
- `Cmd+S` 立即保存并创建文字版本。
- 编辑会话结束及 AI 改写前创建恢复版本。
- 连续输入不逐键创建版本，继续遵守最近 10 个文字版本限制。
- 界面持续显示正在保存、已保存或保存失败。

### 6.7 冲突与标注

- 写入前比较 Markdown 指纹。
- 检测到其他设备或工具的修改时暂停自动保存。
- 用户可以选择重新载入、保留我的版本或查看冲突。
- 保存成功后重建派生 HTML、目录和全文索引。
- 现有标注按新正文重新解析；无法恢复的标为“位置待恢复标注”。

### 6.8 动作前保存屏障

执行 AI 总结、AI 解释、发布预览、导出或版本操作前，必须等待当前编辑内容保存完成。保存失败时阻止依赖已保存正文的动作，并保留当前编辑内容。发布还要求正文引用的云端媒体全部上传完成。

## 7. 云端媒体

### 7.1 Markdown 引用

- 图片和附件上传到私有七牛云。
- Markdown 保存稳定引用 `media://qiniu/<objectKey>`。
- 不保存短期签名 URL。
- 不要求公开 Bucket 或永久 CDN 链接。
- 对象键采用 `library-media/<sha256-prefix>.<ext>` 内容寻址。

### 7.2 上传

- 插入媒体后立即显示本地预览和等待上传状态。
- 设备在 Application Support 中维护待上传队列。
- 无网络时允许继续编辑和保存待上传引用。
- 应用重启后可继续上传。
- 单文件上限 50MB，默认保留原始内容，不自动压缩。
- iOS 在蜂窝网络上传超过 10MB 文件前要求确认。
- 同内容跨笔记、跨设备只上传一个对象。

### 7.3 鉴权

- Mac 与 iOS 共用一段随机 Bearer 密钥调用笔记媒体接口。
- 媒体密钥在设置页配置，底层保存在本机钥匙串，不写入普通配置或 iCloud。
- 服务端只保存媒体密钥哈希，并用 `Authorization: Bearer` 校验请求。
- 第一版不区分设备、不设置作用域，也不支持单设备撤销；轮换密钥会使所有设备失效。
- 发布、回滚、下架和删除文章继续使用 Ed25519 发布签名，不受媒体密钥影响。
- 永久七牛 AccessKey/SecretKey 只保存在 Web 服务端。
- 客户端设置页只显示服务端返回的 Bucket、域名、上传端点和连接状态。
- 当前版本允许 HTTP 媒体地址，但设置页必须显示密钥可能被截获的风险提示。

### 7.4 读取与缓存

- 签名下载 URL 只存在于内存和短期缓存，不写入 Markdown 或 manifest。
- 渲染器按对象键换取签名 URL。
- 已查看媒体进入可清理的本地派生缓存。
- 设置页显示缓存大小并提供清除入口。
- 缓存丢失不影响 Markdown 正文；有网络时可重新下载。

### 7.5 清理

- 删除正文媒体不立即删除七牛对象。
- 历史文字版本仍可引用旧媒体。
- 设置中的媒体管理先扫描引用、显示数量和大小，再由用户确认清理。
- 未引用媒体清理必须有服务端二次校验。

### 7.6 与发布媒体隔离

- 笔记媒体使用独立登记和清理生命周期。
- 发布媒体使用独立对象命名空间。
- 发布时将笔记媒体登记或复制到发布媒体命名空间。
- 删除笔记或清理笔记媒体不得影响已发布文章和历史发布版本。

### 7.7 历史媒体

- 旧 `.studyitem/source/media` 保持原样。
- 设置中的“扫描并迁移历史媒体”展示文件数、大小和引用后再执行上传。
- 不自动上传用户历史私人媒体。

## 8. iOS 适配

### 8.1 共同能力

- 共享 Markdown 编辑器内核和云端媒体引用。
- 支持新建、重命名和删除文件夹。
- 支持在指定文件夹原地新建 Markdown 笔记。
- 支持通过文件选择器或分享入口导入材料。

### 8.2 iPhone

- 保留资料库、收件箱、搜索、复习四个 Tab。
- 知识库和文件夹使用下钻导航。
- 长按菜单提供文件夹和材料操作。
- “移动到…”表单替代三栏拖放。
- 不提供可调栏宽，也不模拟桌面侧栏。

### 8.3 iPad

- 宽屏使用知识库、统一文件夹与学习材料树、阅读/编辑三栏。
- 目录树与 Mac 共用层级、排序、选择、数量和展开状态规则。
- 支持适合触控的拖放。
- 窄窗口和分屏自动退回下钻导航。

## 9. 服务端与数据变更

### 9.1 新增能力

- 独立笔记媒体登记与状态转换。
- 签名上传凭据接口。
- 按对象键换取短时下载 URL 的接口。
- 上传完成后的对象存在性、大小、类型和内容哈希校验。
- 引用扫描和受控清理接口。
- 发布时将笔记媒体登记或复制到发布媒体命名空间。

### 9.2 数据隔离

发布媒体表继续服务文章版本；笔记媒体使用独立数据结构。二者都引用同一个私有七牛 Bucket，但对象前缀、状态机、引用和清理任务相互隔离。

### 9.3 无新建数据库备份

本轮不改变 ADR-0016。笔记媒体登记属于云端派生元数据；Markdown 中的对象引用仍是本地真相。MySQL 或服务端元数据丢失后，设备可从 Markdown 扫描引用并重新登记可用对象。

## 10. 验收标准

| 编号 | 验收标准 |
| --- | --- |

## 11. 分阶段交付

### 阶段 A：工作区骨架

- 调整 Mac 信息架构和设置入口。
- 完成栏宽拖动、折叠、状态持久化和阅读区自适应。
- 把文件夹编辑迁入材料目录栏，并将文件夹与学习材料合并为统一树。

### 阶段 B：目录整理

- 统一目录树、右键菜单、拖放和动画。
- 多选材料转移。
- 重命名冲突、删除和回收站边界。
- iOS 下钻导航与移动表单。

### 阶段 C：编辑器

- 共享 WebKit 编辑器内核和 Markdown 序列化。
- 阅读态/编辑态切换、标题同步、源文本模式。
- 首版格式、斜杠菜单、块拖拽、大纲和查找。
- 自动保存、版本、冲突和保存屏障。

### 阶段 D：云端媒体

- 服务端笔记媒体登记、上传、读取、校验和清理。
- Apple 待上传队列、下载缓存和设置页状态。
- 发布媒体命名空间隔离。
- 历史本地媒体迁移工具。

### 阶段 E：跨端与验收

- iOS 编辑器接入和 iPad 多栏。
- 数据迁移、无障碍、性能和错误恢复。
- Mac/iOS/Web 端到端验收。

## 12. 主要风险

| 风险 | 应对 |
| --- | --- |
| WKWebView 编辑器在中文输入、快捷键和无障碍上行为不一致 | 建立 Mac/iOS 共用的输入法、选区、撤销和键盘测试集 |
| Markdown 无法无损表达全部富文本能力 | 限制首版能力，未知块保留为源码，转换不无损时阻止保存 |
| 字节级和语义级 Markdown 往返不一致 | 建立固定 Markdown 样本库和序列化差分测试 |
| iCloud 外部修改与自动保存冲突 | 指纹检查、暂停保存、显式冲突选择 |
| 七牛或发布服务不可用 | 本地待上传队列、正文继续可编辑、媒体明确显示缺失状态 |
| HTTP 链路截获共享媒体密钥 | 在设置页持续显示风险提示；第一版按产品决定不强制 HTTPS |
| 云端元数据丢失 | Markdown 扫描恢复可访问对象引用，媒体登记可重建 |
| 编辑器范围膨胀成语雀全量复刻 | 以第 6.4 节能力清单作为首版边界，其他能力逐项立项 |
